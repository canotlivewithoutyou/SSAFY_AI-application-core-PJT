# 요구사항 정의서

> 열려있DOC — 전국 야간·휴일 병원·약국 방문 플래너
> SSAFY AI 코어 프로젝트 3회차 · Agent 기반 도메인 플래너 서비스 · 2026-11-20 기준

## 1. 서비스 개요

야간이나 휴일에 차로 병원·약국을 찾는 사람에게 **출발해서 도착할 때까지 운영하는 방문 후보**를 제안합니다. 가까운 곳도 이동 중에 문을 닫을 수 있으므로, 출발 시각과 실제 차량 경로 소요시간을 함께 봅니다.

| 항목 | 내용 |
|---|---|
| 이용 지역·이동 수단 | 전국, 자동차. 첫 검증 지역은 성남 판교 |
| 사용자 입력 | 출발지, 기관 종류(병원/약국), 출발 날짜·시각, 허용 이동시간 |
| 결과 | 기관명·주소, 예상 주행시간과 도착 시각, 방문일 운영시간, 선택 근거, 제외 후보와 사유 |
| 저장 결과물 | 방문 계획 (기관, 방문 날짜, 출발지·목적지 좌표, 출발·도착 시각, 주행시간, 운영 구간, 선택 근거, 생성 일시) |
| 위험 도메인 안내 | 의료 도메인이므로 모든 추천 응답과 화면 하단에 아래 문구를 표시 |

> 공개 운영시간과 예상 이동시간을 바탕으로 한 방문 안내입니다. 실제 운영 및 접수 여부는 방문 전 기관에 확인해 주세요. 이 서비스는 전문가의 의료 상담을 대신하지 않습니다.

## 2. 도메인 선택 조건 충족 근거

### 2.1 외부 API (서로 다른 정보 3종 이상)

| 외부 API | 제공 정보 | Tool |
|---|---|---|
| 카카오 로컬 키워드 장소 검색 | 출발지 이름·주소·좌표, 동명 장소 | `search_place` |
| 국립중앙의료원 전국 약국 정보 조회 / 전국 병·의원 찾기 (위치정보 조회) | 주변 기관 후보, 기관 ID(hpid), 좌표 | `search_nearby_institutions` |
| 국립중앙의료원 같은 서비스 (기본정보 조회) | 요일·공휴일별 운영 시작·종료 시각 | `get_institution_detail` |
| 카카오모빌리티 자동차 길찾기 / 미래 운행 정보 길찾기 | 출발 시각 기준 예상 주행시간·거리 | `get_driving_route` |
| SSAFY GMS 경유 OpenAI `gpt-4o-mini` | 자연어 요청의 조건 구조화 | 요청 분석 (Tool 아님) |

출처와 호출 한도·이용 조건은 `README.md`의 "외부 API 출처와 이용 조건"에 정리했습니다.

### 2.2 판단이 필요한 대표 요청

| 대표 요청 | Tool 없이 LLM만 답하면 틀리는 지점 |
|---|---|
| "성남 판교역 신분당선에서 오늘 21시에 출발해 차로 20분 안에 갈 약국 찾아줘" | 직선거리만으로는 도착 시각과 도착 시점 운영 여부를 알 수 없음 |
| "30분 뒤에 출발하면?" (후속 요청) | 출발 시각이 바뀌면 경로 소요시간과 마감 전 도착 여부가 달라짐 |
| "판교역에서 출발할래" | 성남과 서천에 같은 이름의 역이 있어 다른 지역을 조회할 수 있음 |
| "이 서비스는 어떻게 써?" | Tool이 필요 없는 요청. 외부 호출 없이 안내해야 함 |

재계획이 의미 있는 이유: 가장 가까운 후보가 도착 전에 마감하거나 경로를 확인할 수 없으면, 같은 출발 시각·이동시간 상한으로 다음 후보를 다시 판단해야 합니다.

### 2.3 저장·관리할 결과물

방문 계획. 저장·목록·상세·수정·삭제를 제공하고, 같은 날짜에 출발~도착 시간이 겹치는 계획이 있으면 저장은 하되 경고합니다.

설계 시험에 따른 변경
- 동명 장소(성남·서천 판교역)를 확인한 뒤, 장소 검색 결과에 `ambiguous`를 두고 기관 조회 전에 되묻도록 바꿨습니다.
- 길찾기 104 오류를 확인한 뒤, 경로 실패를 후보 제외와 재계획 사유로 쓰고 직선거리 환산을 하지 않기로 정했습니다.
- 실연동 중 GMS 키가 OpenAI 기본 주소로 전송되어 401이 나는 문제를 확인하고, `OPENAI_API_BASE` 설정을 실행 절차에 추가했습니다.
